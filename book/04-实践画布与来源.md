## 附录：把一次工作，变成下一次的起点

挑一件最近做过的事，用检查表找缺口，用案例索引借动作，再用记录卡追踪真实交付。需要哪一部分，就从哪一部分开始。

### 一、先检查手里这份东西

拿出一份准备继续使用的材料，回答五个问题。

| 检查问题 | 写下一个具体答案 |
| --- | --- |
| 谁会在什么情况下用它？ | 例如：销售准备首次客户拜访时，用它筛选要问的问题。 |
| 它能让下一次少做什么？ | 少查哪些资料，少作哪次判断，或避免哪种返工。 |
| 从哪里找到、怎样使用？ | 一个固定文件、模板或清单入口，以及必要的输入。 |
| 它属于谁，能用到哪里？ | 个人方法、岗位资料或组织数据；允许查看和使用的范围。 |
| 什么变化会让它失效？ | 政策变化、产品更新、客户情况改变；谁负责检查和修正。 |

**第一行答不出来，先别忙着整理。第二行答不出来，找一次真实任务试用。** 剩下三行，决定它能不能被稳定调用。

权限按具体材料确认：一般方法和客户记录可能放在同一个文件里，仍有不同的使用约定。组织资料在允许的环境内调用。

### 二、五类资产，各看一个真正有用的信号

每类资产先选一个可持续记录的信号。

#### 问题资产：有没有人愿意往前走一步

把问题写成“谁在什么场景，为哪件事付出什么代价”，记两列：出现次数，愿意配合验证的人数。

**看行动。** 提供样本、参与试用、投入时间或付费，比口头赞同更能支持下一步。找不到试用者，先缩小对象与场景，或改善接触条件。

#### 数据资产：能不能找得到、说得清、用得上

抽一条常用记录，检查来源、日期、条件与结果，再补缺项。

看两个数：**关键字段齐全的记录数，实际用过的记录数。** 计算比例时，用同一批记录作分母。

查找慢，统一字段与入口；常查到旧信息，补有效范围和更新日期。业务记录也要与当前规则、产品资料对照。

#### 判断资产：当时为什么这样想，后来怎样了

每次重要判断留下三句：

> 当时根据什么作出判断？  
> 哪个条件变化，会让我改主意？  
> 后来发生了什么，哪里需要修正？

每月回看几次，分清偏差来自信息缺失、规则过期还是特殊条件，再决定补数据、改标准或加检查。

记录失败及原因，避免只留下成功。不同难度与风险的任务，不宜合成一个总准确率。

#### 流程资产：从接到任务到验收，到底用了多久

同类任务记录**总耗时、首次提交是否通过**，包含准备、生成、检查、沟通与返工，比较时保持范围和标准接近。

维护时间另记。省两小时、维护四小时，就检查质量收益是否值得；否则缩小或停用。报价和最终验收等人工节点，也应计入流程。

#### 信任资产：别人有没有真正使用，并愿意再来

交付后问：“后来用在哪一步？”记录是否再次使用、为何回来或为何停止。

重复使用率只统计已有再次使用机会的人；一次性需求没有复购，不能直接算信任流失。样本少时，先记人数和原因。出错后的解释与修正也要记录。

### 三、把这四笔账放在一起看

月底用十分钟检查四笔账。

| 这笔账 | 最简单的记录 | 它提醒你什么 |
| --- | --- | --- |
| 复用 | 本月哪些材料被再次调用，分别帮了什么忙？ | 找到真正值得维护的少数积累。 |
| 交付 | 同类任务的总耗时、返工和使用结果怎样变化？ | 判断是否减少重复劳动，而非只加快生成。 |
| 维护 | 更新、纠错和沟通花了多少时间？ | 检查节省下来的投入是否被后续负担吃掉。 |
| 选择 | 有没有多一种接项目、拒绝项目或安排时间的余地？ | 看积累是否开始改变你的处境。 |

变化不必立即体现为收入。把少了一次错误、减少哪项返工等结果记具体，供下月比较。长期不用的材料停止主动维护，必要历史保留日期和用途。

### 五、四周实验：把一次工作变成下一次可用的资产

选择正文 3.2.5 中最适合自己的一个起点：信息比较、专业判断，或重复交付。下面四个行动分别对应一周；低频任务可以延长，不必为了进度编造样本或反馈。

| 时间 | 行动与具体产物 | 继续前的检查 |
| --- | --- | --- |
| 第一周 | 选择一个真实使用者和一个具体任务，填画布中的“问题与对象”；记下原方法的完整耗时。 | 找不到试用者、验收人或可用资料时，先缩小范围。 |
| 第二周 | 整理最多十条已有样本，填写来源、日期、条件、结果及例外；不足十条如实记录。 | 划掉无权使用的材料，区分不同条件和过期资料。 |
| 第三周 | 完成画布中的“最小流程”，用正常、缺信息、旧资料三个样例试跑，记录 AI 错误和人工修正。 | 关键依据不能核实、验收责任不清或错误无法拦截时，不进入真实交付。 |
| 第四周 | 完成一次真实交付，用下方记录卡记耗时、反馈和可复用部分。 | 没有实际使用或反馈时标为试跑；不能据此认定有效。 |

#### 四周实验画布

复制一份填写，一次只处理一种任务。

| 画布 | 填写内容 |
| --- | --- |
| 问题与对象 | 谁在什么情况下，需要完成什么决定或任务？原来卡在哪一步？ |
| 飞轮起点 | 信息比较 / 专业判断 / 重复交付：选一个；第一份交付物是什么？ |
| 现状基线 | 原方法从准备到验收用了多久？原有质量或返工情况是什么？没有记录就从下一次开始记。 |
| 可用材料 | 样本、来源、日期、适用条件；哪些材料有权用于本次和后续复用？ |
| 最小流程 | 输入：＿＿＿ → AI 负责：＿＿＿ → 人核对：＿＿＿ → 输出与验收人：＿＿＿。 |
| 停止与转交 | 哪些信息缺失、资料过期或高风险情况必须停下，由谁处理？ |
| 留下的资产 | 问题：＿＿＿；数据及来源：＿＿＿；判断及例外：＿＿＿；流程模板：＿＿＿；使用反馈：＿＿＿。不适用的留空。 |
| 验证结果 | 是否真实使用：＿＿＿；总耗时：＿＿＿；维护时间：＿＿＿；反馈和返工：＿＿＿；下一步：继续 / 缩小 / 停止。 |

**填写示例｜新人产品答疑**：对象是需要回答常见适用条件问题的新人；交付物是一页带来源的答疑稿。输入为获准使用的现行产品资料和三条新人问题；AI 提取相关条件并起草，人核对版本、适用范围和例外。资料过期或客户条件不完整时转业务负责人。试用后保留来源、修改理由和新人仍看不懂的问题；是否节省时间，等真实记录后再填。

#### 一次交付记录卡

一次任务填一张，不需要为了填满而增加工作。

| 记录 | 填写内容 |
| --- | --- |
| 任务与使用范围 | 服务对象、具体问题、资料来源与日期；哪些可在后续复用？ |
| 判断与验收 | 关键依据、例外和人工验收人；AI 做了什么，人修改了什么？ |
| 实际结果 | 是否使用，使用在哪一步；反馈、错误或返工是什么？尚无反馈就留空。 |
| 时间账 | 准备、生成、检查、沟通、返工分别多久？合计交付时间：＿＿＿；另记维护时间：＿＿＿。 |
| 下次行动 | 哪个材料或步骤可直接复用？哪些要更新、暂停或删除？ |

### 六、九十天复盘：决定下一笔投入

沿用四周实验的同一个任务，不必再建立一套记录。每次交付填上面的卡，第 5—8 周回看重复使用与例外，第 9—12 周只在条件成熟时试一个相邻变化；到第 90 天左右用下面画布作决定。低频任务按实际完成情况延后复盘。

#### 九十天复盘画布

| 复盘 | 填写内容和判断方法 |
| --- | --- |
| 使用与问题 | 服务对象与任务：＿＿＿；实际交付 ＿＿＿ 次，其中有反馈 ＿＿＿ 次；重复出现的问题：＿＿＿。无再次使用机会时注明。 |
| 五类资产 | 哪条问题、哪份数据、哪项判断、哪个流程、哪条使用反馈被再次调用？逐项记具体文件或记录；没有就留空。 |
| 时间与质量 | 可比较的原方法：＿＿＿ 分钟/次；新方法：＿＿＿ 分钟/次；本期维护：＿＿＿ 分钟。净节省＝可比较交付的原耗时合计－新耗时合计－维护时间；未记录基线就不计算。另记首次通过、返工和具体错误，不把质量折算成时间。 |
| 人工判断与权限 | 是否仍能解释依据、例外和验收标准？资料是否仍在有效期和授权范围内？不能确认时暂停相关步骤。 |
| 下一步与收益 | 选择继续 / 缩小 / 暂停 / 停止：＿＿＿；依据：＿＿＿；下一次检查日期或触发条件：＿＿＿；节省的时间准备怎样使用：＿＿＿。 |

例如，四周实验中的新人答疑如果被多次使用，但每次都要重新核对产品版本，就先补版本检查和更新责任；如果实际没有人再用，记录原因并停止主动维护。只有原方法、新方法的任务范围与验收标准相近，时间比较才有意义。

## 来源说明

官网和公开仓库支持产品结构与方法说明；客户和从业者分享用于理解实践，效果数字按自述处理；研究需按样本、设计和版本阅读，相关性不写成因果。正文中的假设场景与时间账仅作演示。

**新增案例的材料范围。** 十张案例卡依据作者整理的实践案例材料。过程描述用来解释工作机制；未独立审计的营收、增长率、缺陷率与效率数字，没有写入卡片。卡片“WHAT学到什么”中的积累方向与起步动作是本书的分析与建议，不表示实践者已完成这些额外动作。材料定位记录留在编辑台账中。

**保留的公开案例与方法。** 数据服务采用官网及 API 说明；写作规则采用公开仓库；内容服务采用运营者公开介绍；责任事故采用法院与仲裁庭文书。中间成果的分层方法参考公开的知识维护说明。它们分别支持产品结构、实践过程或责任边界，不一概当作效果证明。

**研究与实践框架。** 客服研究采用《经济学季刊》正式发表版；效率讨论采用 METR 的历史实验及后续研究说明；判断训练参考概率预测研究；知识工作中的核验问题参考 CHI 2025 调查与认知债务讨论。Agent 的验收与渐进扩展建议参考工程实践文章。正文原有链接保留，研究的样本与限制仍在相关段落说明。

关于数字的一点说明：正文采用《经济学季刊》正式发表版的客服研究数字（5,172 名客服，平均约 15%）。同一研究的早期工作论文是 5,179 名客服、约 14%，两个版本不要混用。

三种飞轮与九十天安排，是本书据这些材料提出的实践框架。研究提供局部证据，真实案例提供可观察的做法；它们都代替不了读者在自身条件下的验证。
